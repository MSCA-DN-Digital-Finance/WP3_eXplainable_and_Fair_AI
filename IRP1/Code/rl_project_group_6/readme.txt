Reinforcement Learning Project: Portfolio Management

This repository contains the implementation and experimentation of reinforcement learning (RL) strategies for portfolio management. The project is structured to facilitate modular development and testing of various RL agents and market environments.

Repository Structure:

agents.py: Contains the implementation of different RL agents, such as Q-Learning and baseline agents, which interact with the environment to learn optimal portfolio management strategies.​

environments.py: Defines the market environments in which the agents operate, including the dynamics of asset prices and portfolio valuations.​

generators.py: Implements various data generators that simulate market conditions, providing the environments with synthetic data for training and testing the agents.​


Notebooks:
These Jupyter notebooks are used to run experiments, analyze results, and compare the performance of different agents.​
